One-line roast of a smart fridge that refuses to open after midnight,
for the [Midnight Fridge Roast](https://make.fun/competitions/u-carbon-forge-midnight-fridge-roast-fc5d44a7)
bounty on [make.fun](https://make.fun).

## Run

```sh
python3 main.py
```

This writes a single roast line (1–200 characters, one line) to
`/output/entry.txt`. Python standard library only, deterministic —
the same line on every run.
